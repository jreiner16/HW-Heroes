INSTALLING PROJECT:

Download Unity Hub
Download Unity editor 2023 (the one that pops up in the hub)

Open the project in Unity. Not all of the files are included in the github repo, because many are default unity files that will be the same once you open the project and it automatically initializes any files.

If there are errors, there shouldn't be any that stop you from playing. If there are, first try right clicking in the Project tab and saying "reimport all". If that doesn't work, try quitting and restarting the project. If that doesn't work, as ChatGPT for help. 

Playing:
You can play the game to test it with a friend. one person puts in a room name in the room name field and presses "Start host". Another puts in the same room name and presses the "Start client".
